# App Icons Guide

## Required Icon Sizes

### Android (Google Play Store)
- **Primary Icon**: 512 × 512 pixels (PNG, max 1MB)
- **Adaptive Icon Foreground**: 108 × 108 pixels 
- **Adaptive Icon Background**: 108 × 108 pixels
- **Legacy Icons**: 48×48, 72×72, 96×96, 144×144, 192×192 pixels

### iOS (Apple App Store) 
- **App Store Icon**: 1024 × 1024 pixels (PNG, max 4MB)
- **iPhone Icons**: 60×60, 120×120, 180×180 pixels
- **iPad Icons**: 76×76, 152×152 pixels
- **Settings Icons**: 29×29, 58×58, 87×87 pixels
- **Spotlight Icons**: 40×40, 80×80, 120×120 pixels

## Design Guidelines

### Do's:
- ✅ Simple, clean design
- ✅ High contrast colors
- ✅ Scalable design (looks good at small sizes)
- ✅ Consistent with app theme
- ✅ Use PNG format without transparency for store icons

### Don'ts:
- ❌ No text in icons (becomes unreadable)
- ❌ No overly complex details
- ❌ No transparency in store icons
- ❌ No copyrighted images

## Todo App Icon Ideas:
1. **Checkmark in circle** - Universal symbol for completion
2. **List with checkboxes** - Directly represents functionality
3. **Clipboard with checkmark** - Professional, organized feeling
4. **Simple geometric task list** - Modern, minimalist
5. **Check/tick mark with rounded corners** - Friendly, approachable

## Tools for Creating Icons:
- **Free**: GIMP, Paint.NET, Canva
- **Paid**: Adobe Illustrator, Photoshop, Sketch, Figma
- **Online**: Favicon.io, IconMaker, LogoMaker

## File Naming Convention:
- `app_icon_512.png` - Main Android store icon
- `app_icon_1024.png` - Main iOS store icon
- `adaptive_foreground.png` - Android adaptive foreground
- `adaptive_background.png` - Android adaptive background
